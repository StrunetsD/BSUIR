Помощь по использованию корпусного менеджера

Возможности поиска:

  • По словоформе — поиск точного вхождения слова (например, "романа")
  • По лемме — поиск по нормальной форме (например, "роман" найдёт "роман", "романа", "роману")
  • По части речи — поиск всех слов с указанной частью речи (NOUN, VERB, ADJ и т.д.)

Результаты показывают найденные слова в контексте предложений со ссылкой на полный документ.

Конкорданс показывает слово в его непосредственном контексте. Для каждого вхождения выводится:

  • Несколько слов слева от искомого
  • Само слово (выделено)
  • Несколько слов справа
  • Название документа и автор

Это позволяет изучать употребление слова в разных контекстах.

Статистический раздел предоставляет:

  • Общую информацию о корпусе (количество документов, предложений, слов)
  • Топ-10 самых частотных словоформ и лемм
  • Распределение слов по частям речи
  • Статистику по авторам

Клик на слово или лемму открывает детальную информацию.

В разделе "Документы" представлен полный список всех загруженных текстов с метаданными:

  • Название
  • Автор
  • Жанр
  • Год (если указан)

Можно открыть полный текст документа и экспортировать его в TXT.

Фильтрация позволяет отобрать слова по заданным критериям:

  • По части речи — выберите часть речи из списка, чтобы увидеть все слова этой категории

Клавиатурные сокращения

  • / — фокус на поле поиска
  • ? — открыть эту страницу помощи

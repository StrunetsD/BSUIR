# FRONTEND RULES — дизайн-система «Index Room»

> Это контракт, не рекомендация. Любая правка UI без соответствия этому
> файлу = переделка. Язык интерфейса — английский (вариант 11).

## 1. Концепция

**«Библиотечный каталог / научная картотека»** — интерфейс читального зала
архива: бумага, чернила, красный штамп каталогизатора, монопространственные
индексы, линейная типографика. Никакого «SaaS-дашборда» и «AI-продукта».

Три слова-ориентира: **typographic, calm, precise.**

## 2. Типографика

| Роль | Шрифт | Начертания | Применение |
|---|---|---|---|
| Display | **Space Grotesk** | 500, 700 | Заголовки, логотип, крупные цифры |
| Text | **Spectral** | 400, 400i, 600 | Основной текст, документы, ответы |
| Data | **IBM Plex Mono** | 400, 500 | Ранги, метрики, сниппет-мета, кнопки-ключи |

- Файлы `.woff2` локально в `assets/fonts/` (никаких Google-CDN в рантайме).
- `font-display: swap`; фолбэки: `ui-sans-serif`/`ui-serif`/`ui-monospace`
  (только как fallback — основные шрифты всегда грузятся локально).
- Масштаб (px): 12 · 14 · 16 · 20 · 28 · 40 · 64. Body = 16/1.6 Spectral.
- Заголовки: letter-spacing −0.02em; mono-метки: +0.08em, uppercase.

## 3. Цвет

```css
--paper:        #F6F2EA;  /* фон */
--paper-deep:   #EDE6D8;  /* блоки, шапки таблиц */
--ink:          #14120E;  /* основной текст */
--ink-60:       rgba(20,18,14,.60);
--ink-40:       rgba(20,18,14,.40);
--rule:         rgba(20,18,14,.14);   /* линии, бордеры */
--vermilion:    #D64524;  /* акцент: ссылки, активный ранг, штампы */
--moss:         #2F5D50;  /* вторичный: успех, положительные метрики */
--focus:        #1B4FD8;  /* ТОЛЬКО focus-visible ring */
```

- Светлая тема единственная (демо в аудитории, проектор).
- Запрещены: дефолтные синие `#3B82F6`, фиолетовые градиенты, тёмные
  «стеклянные» панели, тени-облака. Тень допустима одна: `0 1px 0 var(--rule)`.

## 4. Сетка и ритм

- Контейнер 1280px, боковые поля 32px; 12-колоночная сетка, gutter 24px.
- Отступы кратны 4: 4/8/12/16/24/32/48/64/96.
- Страница поиска: слева (8 колонок) — поиск+выдача; справа (4 колонки,
  sticky) — панель LLM-ответа и карточка фильтров.
- Горизонтальная линейка `1px var(--rule)` — главный разделитель секций.

## 5. Компоненты (канонические)

### 5.1 Поисковая строка (герой)
Крупное поле на бумаге: border 2px ink, радиус 10px, слева mono-метка
`QRY`, справа кнопка Search (ink-фон, paper-текст). Placeholder:
`Natural language query — try: battery storage for renewable energy`.
Под строкой — чипы моделей (`BOOLEAN / TF-IDF / BM25 / DENSE / HYBRID`,
активный — залит ink). Кнопка «Expand» (LLM) — outline vermilion.

### 5.2 Результат
Строка выдачи — не карточка, а «каталожная запись»:
```
01 │ Grid-scale batteries: the missing link          ████████░░ 12.44
   │ Utility-scale battery storage has become the critical…
   │ matched: batteri · storage · renewabl · energi   2025-03-14  #61
```
- Ранг — mono 2-значный с ведущим нулём; шкала релевантности — 10-сегментный
  bar (vermilion заполнение); term-подсветка в snippet — underline 2px
  vermilion, НЕ заливка фона.
- Ссылка на документ — title, hover: underline. Вся строка кликабельна.

### 5.3 Таблицы (метрики, коллекция)
Шапка — paper-deep, mono uppercase 12px; числовые колонки — mono,
выравнивание вправо; лучший результат строки — точка-маркер vermilion
перед значением; hover строки — paper-deep. Никаких зебр.

### 5.4 Графики (Chart.js)
Сетка линий `--rule`, шрифты осей IBM Plex Mono 11px; палитра серий:
`#14120E, #D64524, #2F5D50, #8A6FBF, #B07D2B` (толщина 2px, точки 3px).
Обязательны: легенда сверху, tooltip с mono-значениями, ось 0–1 у метрик.

### 5.5 Состояния (обязательны для всех списков)
- **loading**: скелетон-строки (paper-deep, shimmer 1.2s);
- **empty**: mono-текст `0 results — try fewer or broader terms`;
- **error**: полоса с vermilion-меткой `ERROR` и текстом причины;
- **llm_unavailable**: панель с плашкой `LLM OFFLINE` + кнопка «How to enable»
  (ведёт в Help).

### 5.6 Тосты, модалки, контролы
Тосты — снизу справа, ink-фон, 3 c, mono-метка уровня. Модалки — paper-лист,
шапка с линейкой, закрытие Esc/клик по фону. Кастомный select (модель,
категория): список paper-лист, активный пункт — маркер слева.

## 6. Навигация и клавиатура

- Хеш-роутер: `#/search`, `#/document/:id`, `#/metrics`, `#/collection`,
  `#/history`, `#/help`. Хедер: логотип-штамп `INDEX ROOM` + mono-навигация.
- Клавиши: `/` — фокус в поиск; `j/k` — вниз/вверх по выдаче; `Enter` —
  открыть документ; `Esc` — закрыть модалку/снять фокус. Подсказка
  хоткеев — в футере, mono.

## 7. Микрокопирайт (English, технический)

- Коротко, без восклицаний и «дружелюбного ИИ-тона».
- Глоссарий в Help: POD/POD, POZ/query vector, BM25, RRF, qrels, MAP/NDCG.
- Ошибки — почему и что делать: `LLM unavailable: set MISTRAL_API_KEY in .env`.

## 8. Запрещено (anti-slop, неисчерпывающий список)

1. Шрифты Inter, Roboto, Arial, system-ui как основные.
2. Эмодзи как иконки. Иконки — только inline-SVG спрайт (лупа, документ,
   график, крестик, стрелка), stroke 1.5px, currentColor.
3. Градиентные баннеры, glassmorphism, neumorphism.
4. Ряды одинаковых карточек в 3 колонки.
5. Lorem ipsum и любые тексты-заглушки в демо.
6. Дефолтные HTML-контролы без стилизации (select, button, input).
7. Синие `#3B82F6`/`#2563EB`, purple-градиенты.
8. Спиннеры-«колёса» — только скелетоны/прогресс-полоса.
9. Копия текста «Powered by AI» и подобные штампы.
10. Анимации > 300ms и анимация чего-либо без изменения состояния.

## 9. Чек-лист приёмки (прогонять перед коммитом UI)

- [ ] Шрифты грузятся локально, FOUT < 300ms
- [ ] Все 6 страниц открываются, роутер не ломается по F5
- [ ] Поиск: 5 моделей дают разный порядок на тестовом запросе (скриншот)
- [ ] Подсветка терминов видна, matched_terms соответствует snippet
- [ ] Скелетоны видны при запросе (throttle Slow 3G)
- [ ] Пустая выдача и ошибка 503 LLM отрисованы по §5.5
- [ ] Метрики: таблица + оба графика рендерятся на реальных данных
- [ ] CRUD документа: создать → найти → открыть → похожие → удалить
- [ ] Клавиатурный сценарий `/` → запрос → `j/k` → `Enter` работает
- [ ] Контраст текста ≥ AA (проверить ink-60 на paper)
- [ ] focus-visible виден на всех интерактивных элементах
- [ ] Нет ни одного пункта из §8
- [ ] Viewport 1280 и 1440 без горизонтального скролла
- [ ] Сеть: все вызовы идут на относительный `/api/*`

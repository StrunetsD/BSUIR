# METRICS — оценка качества ИПС (по ROMIP/2004)

> Требование лабы: дать оценку работы ИПС по метрикам, реализовать вычисление
> программно, отображать в виде **таблиц и графиков**. Источник методики:
> 2004_romip_metrix.pdf (упомянут в лабе).

## 1. Постановка

- Стратегии сравниваются на **одной и той же** эталонной разметке:
  15 тестовых запросов × qrels (см. [COLLECTION.md](COLLECTION.md)).
- Ранжирование конкретной стратегии — `model ∈ {boolean, tfidf, bm25, dense, hybrid}`.
- Бинарная релевантность для P/R/F1/AP/RR/R-prec: `grade ≥ 2`.
- Градуированная — только для NDCG: `gain = grade` (0..3).

Обозначения: для запроса q и выдачи размера k —
`R` — общее число релевантных в коллекции (из qrels),
`rel(i)` — релевантность документа на позиции i выдачи.

## 2. Формулы

### Precision / Recall / F1 (на уровне выдачи целиком, k = |выдача|)

```
P = TP / (TP + FP)          R = TP / R_total
F1 = 2·P·R / (P + R)        (0, если P+R = 0)
```

### P@k

```
P@k = (# релевантных в первых k) / k         → P@5, P@10
```

### R-precision

```
R-prec = P@R_total    (точность на первых R_total позициях)
```

### Average Precision и MAP

```
AP = (1/R_total) · Σ_{i: rel(i)} P@i
MAP = mean(AP) по всем запросам
```

### MRR (Mean Reciprocal Rank)

```
RR = 1 / (позиция первого релевантного)     (0, если релевантных нет)
MRR = mean(RR)
```

### NDCG@10

```
DCG@k  = Σ_{i=1..k} (2^rel(i) − 1) / log2(i + 1)
IDCG@k = DCG идеального ранжирования (все оценённые документы, по grade ↓)
NDCG@k = DCG@k / IDCG@k
```

### 11-point интерполированный P-R

Для уровней отзыва r ∈ {0.0, 0.1, …, 1.0}:

```
P_interp(r) = max{ P(π) : π ≥ r }    (максимум точности при отзыве ≥ r)
```
Для уровней, недостижимых в запросе (r > max recall), — вклад 0
(стандарт TREC); усреднение по запросам. Отображается **одной кривой
на модель** в общих осях (график «11-point interpolated average precision»).

## 3. Что выводится в UI (подменю «Metrics»)

1. **Таблица «Модель × метрика»** (агрегаты по 15 запросам):
   columns: model | MAP | avg P@5 | avg P@10 | R-prec | MRR | NDCG@10 |
   macro P | macro R | macro F1.
2. **График A** — 11-point interpolated P-R кривые: все 5 моделей на
   одном поле (Chart.js line).
3. **График B** — bar-чарт сравнения моделей по MAP / NDCG@10.
4. **Per-query дриллдаун**: таблица запрос → AP, NDCG@10, RR, P@5 для
   выбранной модели; сортировка по убыванию.
5. Сохранение прогона (eval_runs) и возможность наложить два прогона
   (например «до/после PRF»).

## 5. Инварианты и тесты

1. Метрика каждой формулы — unit-тест с hand-computed примером
   (ALGORITHMS.md §5 + примеры ниже).
2. Hand-check пример AP: релевантность по позициям [1,0,1,1,0,0,1,0,0,0],
   R_total=4 → AP = (1/4)(1 + 2/3 + 3/4 + 4/7) = 0.7714…
3. NDCG идеального ранжирования = 1.0.
4. 11-point массив неубывает ни на одном шаге при интерполяции max.
5. Прогон без qrels-запросов → ошибка 409, а не деление на ноль.

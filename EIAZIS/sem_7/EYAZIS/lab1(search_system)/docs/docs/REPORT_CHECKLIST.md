## 3. Сценарии приёмки (прогонять на чистом `up`)

1. `docker compose up --build` с нуля → БД засеяна, `/api/health` ok.
2. Поиск `battery storage for renewable energy`, модель bm25 → результаты
   с подсветкой, matched_terms, активной ссылкой.
3. Переключение 5 моделей на том же запросе → порядок меняется осмысленно.
4. «Все слова вместе» на фразовом запросе → выдача только со всеми терминами.
5. Создать документ через UI → найти его поиском → открыть → похожие → удалить.
6. `POST /api/metrics/run` для всех 5 моделей → страница метрик: таблица,
   PR-кривые, bar-чарт; сравнение прогонов.
7. С ключом Mistral: Expand query → чипы; Ask over results → ответ с [n]-цитатами;
   без ключа: те же кнопки дают 503-состояние по FRONTEND_RULES §5.5.
8. Доступ к `http://<LAN-IP>:8080` с другого устройства в сети.
9. История: повторить прошлый запрос одним кликом.
10. Help-страница: глоссарий и формулы открываются, читаемы.

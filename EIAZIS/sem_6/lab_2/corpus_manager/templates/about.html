О проекте

Корпусный менеджер для литературоведческих текстов

Общая информация

Данный проект представляет собой корпусный менеджер, разработанный в рамках лабораторной работы №2 по дисциплине "Естественно-языковой интерфейс автоматизированных информационных систем" (вариант 6: русский язык, литература).

Технические характеристики
  • Язык программирования: Python 3.9
  • Веб-фреймворк: Flask 2.2.3
  • База данных: PostgreSQL 12
  • Морфологический анализатор: pymorphy2
  • Токенизация: NLTK
  • Контейнеризация: Docker, Docker Compose
Функциональные возможности
  • Поиск по словоформам, леммам и частям речи
  • Конкорданс (слово в контексте)
  • Статистика корпуса (частотные характеристики)
  • Просмотр и экспорт документов
  • Фильтрация по грамматическим категориям
  • Морфологическая разметка текстов
  • Поддержка форматов TXT, DOCX, PDF
Структура корпуса

Корпус содержит литературоведческие тексты на русском языке: критические статьи, биографии писателей, литературоведческие исследования, фрагменты художественных произведений.

Таблица Назначение
documents Метаданные документов (название, автор, жанр, год)
sentences Предложения с привязкой к документам
tokens Слова с морфологической разметкой (лемма, часть речи, граммемы)

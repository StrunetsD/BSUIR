Corpus processing report

The development team prepared a small corpus for the laboratory work. Each document contains visible text, headings, and additional semantic blocks. The system extracts the useful content and ignores decorative markup.

After preprocessing, the application splits the text into sentences and annotates every token. The resulting records are stored in the database, where the user can search for words, inspect context windows, and export syntax reports.

The report confirms that automatic loading saves time during demonstrations. It also helps the student compare short, medium, and long texts in one consistent environment.

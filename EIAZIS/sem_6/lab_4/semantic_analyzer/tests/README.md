# Test HTML Files

HTML files in this folder are intended for manual testing of variant 6.

Available samples:

- `test_simple_article.html` - basic article text
- `test_nested_structure.html` - nested semantic blocks
- `test_with_lists.html` - list items mixed with paragraph text
- `test_with_noise.html` - page with `script` and `style` tags
- `test_complex_sentences.html` - longer and more complex English sentences
- `test_tiny_note.html` - very short text
- `test_medium_report.html` - medium sized report
- `test_long_review.html` - long multi-paragraph document
- `test_multi_section_page.html` - several semantic sections
- `test_dialogue_page.html` - dialogue style narrative

Automatic seeding:

- `python seed_test_data.py --reset`
